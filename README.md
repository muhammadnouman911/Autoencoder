## 🎯 What is an Autoencoder?

An **Autoencoder** is a type of neural network that learns to compress and reconstruct data, enabling us to extract meaningful features from raw, unlabelled information. It's commonly used in **data compression**, **denoising**, and **anomaly detection**, and can even generate new data based on learned distributions!
